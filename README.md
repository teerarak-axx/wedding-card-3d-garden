# The Garden Path

การ์ดเชิญงานแต่งงานแบบ 3D พร้อมเซิร์ฟเวอร์และหน้า Admin ภาษาไทย

## เปิดใช้งาน

ต้องใช้ Node.js 24 ขึ้นไป

```bash
npm install
npm run dev
```

- การ์ดเชิญ: http://localhost:4173
- Admin: http://localhost:4173/admin
- ชื่อผู้ใช้: `admin`
- รหัสผ่านเริ่มต้น: ดูค่า `ADMIN_PASSWORD` ในไฟล์ `.env` ที่ระบบสร้างให้อัตโนมัติเมื่อเปิดเซิร์ฟเวอร์ครั้งแรก

รหัสผ่านเก็บในฐานข้อมูลแบบ salted scrypt hash เปลี่ยนรหัสผ่านได้ที่ Admin → ความปลอดภัย การเปลี่ยนค่า `.env` หลังสร้างฐานข้อมูลแล้วจะไม่เปลี่ยนรหัสผ่านของบัญชีเดิม

ข้อมูลเริ่มต้นเป็นตัวอย่างทั้งหมด กรุณาแก้ชื่อ รูป วันงาน สถานที่ ลิงก์แผนที่ และวันปิดรับ RSVP ใน Admin แล้วปิดป้าย “ข้อมูลตัวอย่าง” ก่อนส่งให้แขก

## Production บนเครื่องหรือเซิร์ฟเวอร์ของคุณ

```bash
npm run build
npm start
```

เปิดที่พอร์ตเดียวกัน (4173) หรือกำหนด `PORT` ใน `.env` ใช้ HTTPS เมื่อเปิดให้แขกผ่านอินเทอร์เน็ต โดยให้ reverse proxy ส่งต่อมายังพอร์ตนี้

## ประสบการณ์การ์ดเชิญ

1. ซุ้มประตูดอกไม้ พร้อมป้ายชื่อบ่าวสาวในโลก 3D
2. น้ำพุหินอ่อนสองชั้น มีขอบอ่างและลายดอกไม้แกะสลัก พร้อมกามเทพกางปีกขนนกเป็นชั้น มือจับด้ามธนูและน้าวสายพร้อมลูกศร มีรายละเอียดใบหน้าและผ้าจับจีบ กลางลานอิฐขาวที่มีทางเดินรอบน้ำพุและเก้าอี้แยกจากแปลงดอกไม้
3. กล่องแหวนขอบมนสีขาว บุผ้าสีชมพู มีบานพับ ตัวล็อก และขอบทอง พร้อมแหวนประดับเพชรเจียระไนและหนามเตย ลากหมุนได้ อยู่ในลานข้างทางเพื่อให้เดินต่อได้ กล้องรักษาทิศทางเดิมตั้งแต่ช่วงน้ำพุจนผ่านแหวน
4. ศาลาสีขาวเปิดโล่งที่วางเสาไว้นอกทางเดิน กำหนดการ ธีมชุด และดาวน์โหลดวันงานเป็นไฟล์ปฏิทิน `.ics`
5. ซุ้มปลายทาง สถานที่ ลิงก์ Google Maps และฟอร์ม RSVP

กล้องเดินตามการ Scroll, กดข้ามจุดได้จากแถบนำทาง รูปความทรงจำกดขยายได้ ใช้ธีมขาว–ชมพูและดอกไม้หลากสี บนมือถือเนื้อหาเรียงตามหน้าจอและเลื่อนอ่านได้ครบ พร้อมตัวอักษรและปุ่มขนาดใหญ่ รองรับมือถือ เสียงบรรยากาศที่เปิดเองได้ และโหมดลดการเคลื่อนไหว ถ้าอุปกรณ์ไม่รองรับ WebGL ยังสามารถอ่านเรื่องราวและส่ง RSVP ได้

## Admin

- เข้าสู่ระบบด้วย cookie session แบบ HttpOnly อายุ 12 ชั่วโมง
- ดูยอดคำตอบรับ จำนวนคนมาร่วมงาน และคนที่ไม่สะดวกมา
- ค้นหา กรอง ลบคำตอบรับ และส่งออก CSV (รองรับภาษาไทย)
- แก้ข้อมูลบ่าวสาว วันเวลา สถานที่ แผนที่ และวันปิดรับ RSVP
- แก้เรื่องราว อัปโหลดภาพ JPG/PNG/WebP สูงสุด 4 MB หรือใส่ URL แบบ HTTPS
- เพิ่ม/แก้/ลบช่วงเวลาในกำหนดการ สูงสุด 12 ช่วง
- เพลงประกอบ: อัปโหลด MP3/M4A/OGG/WAV สูงสุด 20 MB หรือใส่ลิงก์ HTTPS ไปยังไฟล์เพลงโดยตรง ทดลองฟัง ตั้งชื่อ ปรับเสียง เปิด/ปิด และนำเพลงออกจากการ์ด
- เปลี่ยนรหัสผ่านและออกจากทุกเซสชัน

รูปและเพลงที่อัปโหลดจะใช้บนการ์ดเมื่อกดบันทึกการเปลี่ยนแปลง แขกกดไอคอนเสียงในแถบด้านบนเพื่อเล่นหรือหยุดเพลง เพลงจะเล่นวนและใช้ระดับเสียงที่ตั้งจาก Admin ข้อมูลที่แก้ไขจะแสดงเมื่อเปิดหรือรีเฟรชการ์ดเชิญ

## ข้อมูลถาวร

- `data/garden.sqlite` — การตั้งค่า, RSVP, รหัสผ่านที่ hash แล้ว, เซสชัน
- `data/uploads/` — รูปและเพลงที่อัปโหลด
- `.env` — รหัสผ่านเริ่มต้นและพอร์ต

สำรอง `data/` เป็นระยะ SQLite ใช้ WAL จึงควรปิดเซิร์ฟเวอร์ก่อนคัดลอก หรือใช้ SQLite backup API เพื่อสำรองขณะเปิดใช้งาน ห้ามลบฐานข้อมูลหากต้องการเก็บรายชื่อแขก ทั้งข้อมูลและ `.env` ถูกยกเว้นจาก Git

## ทดสอบ

```bash
npm test
npm run build
```

API tests ใช้ฐานข้อมูลชั่วคราวแยก ตรวจการบันทึก/ตรวจข้อมูล RSVP, login, สิทธิ์ Admin, CSV, แก้การ์ด, วันปิดรับ, cross-origin requests, อัปโหลดรูป และเปลี่ยนรหัสผ่าน

มี browser checks สำหรับ Chrome/Playwright เมื่อเปิดเซิร์ฟเวอร์แล้ว:

```bash
node tests/browser-check.mjs
node tests/forms-check.mjs
node tests/layout-check.mjs
node tests/music-check.mjs
node tests/plaza-check.mjs
node tests/journey-check.mjs
```

`music-check.mjs` ใช้เซิร์ฟเวอร์ ฐานข้อมูล และไฟล์เพลงชั่วคราวแยกจากข้อมูลจริง ทดสอบการอัปโหลดและเปิดเพลงจริงบนเบราว์เซอร์

`forms-check.mjs` ใช้ข้อมูลตัวอย่างของเว็บนี้ ส่งคำตอบรับทดสอบ แก้ชื่อชั่วคราว แล้วคืนค่าเดิมและลบคำตอบรับทดสอบ ไม่ควรรันบนเว็บงานจริงระหว่างแขกใช้งาน สามารถตั้ง `TEST_URL` และ `CHROME_PATH` ได้
